# 手工计算企宽重复投诉率

调用技能包内的 `scripts/calculate.py` 合并各文件的 `sheet1` 并计算，不修改源文件。不要读取文件中已有的“企业宽带”筛选页，否则会重复计数。

## 输入与筛选

- 至少输入目标月及其历史月份文件。本口径使用6月、7月、8月三个文件，目标月为8月。
- 自动识别表头行；必需字段为 `投诉工单流水号`、`受理时间`、`受理号码`、`服务请求类型`、`业务地市`。
- 仅纳入 `服务请求类型`包含“企业宽带”的记录。
- 分母为目标月受理时间内全部企业宽带投诉记录数。一小时剔除只影响分子候选，不减少分母。

## 重复投诉口径

- 重复Key = `受理号码` + 服务请求类型中从“政企市场”之后开始的完整路径。
- “网络协调单→政企市场→…”与“政企市场→…”截取后路径相同时属于同一Key。
- 只对目标月执行一小时剔除：同一Key按受理时间排序，相邻受理时间小于或等于1小时的后一单不参与分子计算；历史月份不剔除。
- 如果Key在目标月之前已有投诉，目标月经一小时剔除后保留的每张投诉都算重复投诉。
- 如果Key在目标月之前没有投诉，目标月经一小时剔除后的第1张不算重复，从第2张开始每张算1次重复投诉。
- 分子是目标月重复投诉记录数，不是重复Key数。
- 重复投诉率 = 重复投诉记录数 / 目标月企业宽带投诉记录数。

示例：6月1次、7月1次、8月1次计1次重复；6月1次、7月1次、8月2次计2次；只有8月2次计1次；只有8月3次计2次。

## 地市口径

分母按每张目标月投诉记录的 `业务地市`归属；分子按每张目标月重复投诉记录自身的 `业务地市`归属。全省使用全省分子除以全省分母，不平均地市比率。

## 运行

```bash
python3 scripts/calculate.py \
  --input "/absolute/path/to/6月.xlsx" \
  --input "/absolute/path/to/7月.xlsx" \
  --input "/absolute/path/to/8月.xlsx" \
  --month 2026-08 \
  --json-output "/absolute/path/to/企宽重复投诉率_2026-08.json" \
  --csv-output "/absolute/path/to/企宽重复投诉率_2026-08.csv"
```

运行后报告全省及各业务地市的分子、分母、重复投诉率，并核对 `quality` 和 `audit` 中的一小时剔除记录、重复投诉明细、空Key及空地市情况。
