# 手工计算互联网专线环节自动率

调用技能包内的 `scripts/calculate.py` 读取 CSV，不修改源文件，不手工计数。

## 输入与指标映射

必需字段为 `二级编排工单号`、`环节名称`、`地市`、`业务类型`、`工单类型`、`处理人`、`处理意见`。先筛选 `业务类型=互联网专线`，再计算：

| 输出指标 | 源数据 `工单类型` | 目标 `环节名称` |
|---|---|---|
| 互联网专线-开通-组网方案自动率 | 开通 | 组网方案 |
| 互联网专线-移机-组网方案自动率 | 变更 | 组网方案 |
| 互联网专线-移机-资源反馈自动率 | 变更 | 资源反馈 |
| 互联网专线-拆机-组织资源释放自动率 | 拆除 | 组织资源释放 |

源数据当前以 `变更` 表示移机。除非输入已通过权威关联关系筛成纯移机订单，否则结果中必须注明“变更暂按移机统计”。

## 工单口径

- 唯一工单使用 `二级编排工单号`，不得改用 `工单编号` 或 `EOMS工单号`。
- 自动处理条件为 `处理人`包含“自动”，或者等于“系统管理员”，比较前去除首尾空格。
- 分母是包含目标环节的去重工单数；缺少目标环节的工单单列审计，不进入分母。
- 分子是目标环节全部记录都由自动处理人处理的去重工单数。任一记录为人工、空值或未知账号，整单不自动。
- 自动率 = 自动工单数 / 目标环节工单数。分母为 0 时输出 `null` 或“无数据”。
- 全省自动率使用全省分子除以全省分母，不平均各地市百分比。
- 同一工单出现多个地市时，从正式指标排除并列入地市冲突审计。
- 不要根据 `处理意见` 中的“自动”字样判断自动处理。

当源文件已经代表指定完结工单周期时，不要再按单条环节的结束时间过滤；同一工单的早期环节可能发生在统计期之前。

## 开通组网非自动原因

在 `业务类型=互联网专线`、`工单类型=开通`、`环节名称=组网方案` 范围内，按 `二级编排工单号`统计：

- 目标环节至少一条记录不满足自动处理条件，整单属于非自动工单。
- 只检查该工单中非自动处理记录的 `处理意见`。
- 至少一条处理意见包含“工程施工”，该工单计入工程施工原因一次。
- 至少一条处理意见为空，该工单计入空原因一次。
- 工程施工占比和空原因占比的分母均为非自动工单数。
- 按工程施工工单数从高到低输出前三地市；并列时按地市名称排序。
- 工程施工和空原因分别独立判断，同一工单满足两项时可分别计入，但每项最多计一次。

## 运行

从本技能目录执行：

```bash
python3 scripts/calculate.py \
  --input "/absolute/path/to/资管专线.csv" \
  --json-output "/absolute/path/to/互联网专线自动率.json" \
  --csv-output "/absolute/path/to/互联网专线自动率.csv"
```

脚本支持 UTF-8、UTF-8 BOM 和 GB18030 CSV。运行后核对 JSON 的 `audit`：缺失目标环节、自动与人工混合处理、地市冲突均需报告。还要报告开通组网非自动工单数、工程施工及空原因的工单数和占比、工程施工前三地市。最终结果同时展示每项指标的实际分子和分母。
