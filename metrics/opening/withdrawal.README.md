# 一体化专线开通撤退单率

## 1. 指标用途

本模块从 MySQL 的 `integration_opening` 数据集计算专线开通撤退单率，不读取原始 Excel 或 `export` 目录。

计算脚本：`metrics/opening/withdrawal.py`

## 2. 运行

```bash
python3 metrics/opening/withdrawal.py \
  --month 2026-08 \
  --mode both
```

默认输出：`outputs/专线开通撤退单率_开始日期_结束日期.json`。

## 3. 默认暂行口径

- 默认周期：月报月的上月26日至本月25日；例如2026年8月月报使用`2026-07-26`至`2026-08-25`；
- 时间字段：`工单结束时间`，起止日期均包含全天；
- 基础条件：`工单数据来源=二编`、`工单类型=开通`；
- 业务范围：默认使用固定排除后的全部业务类型；可用`--business-type`进一步限定；
- 业务类型精确排除：`行业视频行业版平台基础`、`行业视频-行业版`、`5G双域专网`；
- 业务类型关键字排除：包含`跨省`或`跨国`；
- 业务套餐类型关键字排除：包含`跨省`；
- 测试单：工单主题包含“测试”或 `test`时剔除；
- 数据表以`工单号`为主键，指标阶段不再二次去重；
- 分母：周期内筛选并剔除测试单后的正式开通工单总数；
- 分子：其中状态为“已撤单”或“已驳回”的工单数；
- “失败”默认不计入分子；
- 当月竣工量：`工单结束时间`在上月26日至本月25日，且`工单状态=已完成`；
- 当月受理竣工量：上述竣工单中，`派单时间`在本月1日至本月末且不晚于结束时间；
- 当月之前受理竣工量：上述竣工单中，`派单时间`早于当月1日；
- 派单时间缺失或晚于结束时间的竣工单单独审计，不归入以上两个受理分组；
- 口径版本：`1.3.0-provisional`。

公式：

```text
专线开通撤退单率 =（已撤单工单数 + 已驳回工单数）÷ 正式开通工单数
```

`provisional`表示专线范围、测试单识别和“已驳回”等同退单仍需业务确认。

## 4. 可调参数

统计多个专线类型时重复传入 `--business-type`：

```bash
python3 metrics/opening/withdrawal.py \
  --month 2026-08 \
  --business-type 互联网专线 \
  --business-type "MPLS VPN专线"
```

- `--all-business-types`：兼容参数，不额外限定业务类型；固定排除规则仍然生效；
- `--withdrawal-status`：可重复指定，替换默认分子状态；
- `--test-keyword`：可重复指定工单主题测试关键词。

## 5. 结果存储与明细

- `metric_run`：统计周期、口径版本、状态及源ETL批次；
- `result_opening_withdrawal`：全省、地市和业务类型的分子、分母、撤退单率，以及全省当月竣工量和派单月份拆分结果；
- `ads_metric_detail`：全省分母、分子、业务范围剔除、测试单剔除及竣工量拆分明细，可追溯到工单号；
- JSON文件：汇总与质量检查，不包含完整工单明细。

## 6. 核对要求

- 撤退率分母包含周期内筛选并剔除测试单后的全部正式开通工单；
- 当月竣工总量等于当月受理、当月之前受理、派单时间异常三组之和；
- 省级、地市和业务类型撤退率均使用相同公式。
