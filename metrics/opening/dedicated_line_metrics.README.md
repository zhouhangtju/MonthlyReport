# 编排专线开通类指标

## 1. 指标用途

本模块从 MySQL 的 `orch_opening` 数据集计算专线开通量、趋势、产品分布和自动率，不读取原始 Excel 或 `export` 目录。

计算脚本：`metrics/opening/dedicated_line_metrics.py`

## 2. 运行

```bash
python3 metrics/opening/dedicated_line_metrics.py \
  --start-month 2025-09 \
  --end-month 2026-08 \
  --mode both
```

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--database` | 可省略 | 兼容旧命令；MySQL 连接信息写在 `storage/database.py` |
| `--start-month` | 必填 | 趋势起始月份，`YYYY-MM` |
| `--end-month` | 必填 | 最新统计月份，`YYYY-MM` |
| `--mode` | `both` | `file`、`database`或`both` |
| `--output` | 自动生成 | 自定义JSON结果路径 |
| `--batch-size` | `5000` | 流式读取每批记录数，必须大于 0 |
| `--temp-dir` | 系统临时目录 | 月内去重暂存目录，指定时目录须已存在且有可用空间 |

默认输出：`outputs/编排专线指标_YYYY-MM.json`。

## 3. 月份与基础口径

- 月份取接口筛选口径对应的结束时间，兼容 `订单结束时间`、`结束时间`、`完成时间`、`订单完成时间`和 `报结时间`；
- 不使用ETL执行时间或文件入库时间归月；
- 基础筛选为 `订单状态=已完成`；
- 数量按 `订单号`去重，空订单号按行计数；
- 口径版本为 `1.0.0`。

`quality.rows_missing_order_month`记录无法取得业务月份的记录数，这些记录不会进入月度指标。

## 4. 已实现指标

- 互联网专线已完成开通订单量、环比和同比；
- 重点互联网产品同比；
- 互联网六类产品按月、地市和产品分布；
- MPLS-VPN指定产品开通量、同比、地市和产品分布；
- 传输专线指定六类产品开通量、同比、地市和产品分布；
- 悦享专线动态 IP 版、互联网专线套餐及其他互联网专线的滚动12个月累计开通量和平均月开通量；
- 互联网专线、MPLS-VPN专线、传输专线、视频监控MV专线的开通/移机9环节、拆除6环节自动率及整体自动率；视频监控MV仅统计行业视频MV专线，不包含视频监控；
- 移机六环节、拆机五环节自动率及整体自动率；
- 移机、拆机各地市配置激活自动率。

运行时按月从 `orch_opening` 读取计算所需列，使用 MySQL 流式游标，每批默认 5000 条，不将全年明细装入 Python 列表。为保留跨批次“同月、同业务类型、同订单类型、同订单号最后一条生效”的规则，月内记录在临时 SQLite 文件中去重（缓存限制约 4 MiB），随后逐条读取去重结果累计汇总，完成该月后删除临时文件。SQLite 仅用于临时计算，不改变 MySQL 的业务存储。

内存只保留当前批次、固定维度计数器及月度汇总；同比、环比、滚动 12 个月指标沿用原公式。全部结果仍在计算完成后保存，不会每完成一个月就标记整个任务成功。读取各月份使用同一个 MySQL 一致性快照，避免计算过程中不同月份读到不同版本的数据。

例如统计 2025-09 至 2026-08，为计算同比仍需读取 2025-08。明细已清理的月份继续使用已有月度汇总。数据库日期范围筛选使用原始列“订单结束时间”；上面的日期别名兼容是计算函数对传入记录的处理规则。

该优化针对内存，并不保证数据库查询更快：时间列仍为 LONGTEXT，TRIM 日期筛选可能导致逐月全表扫描。临时磁盘需要容纳单月去重明细；正常完成及 Python 异常退出会清理，强制终止进程可能留下 `opening_month_*` 临时目录。可以用 `--temp-dir` 指定空间充足的本地目录。

原 `calculate()` 和 `load_rows()` 保留用于兼容与结果对照，命令行 `run()` 已切换至流式流程。指标结果使用批量 SQL 写入，JSON 与 PPT 数据格式不变。

自动率保存实际分子和分母。分母为0时 `metric_value`为 `null`，不会把无数据表示成0%。

## 5. 结果存储

- `metric_run`：统计周期、口径版本和源ETL批次；
- `result_orchestration_opening`：指标编码、月份、产品、地市、环节、分子、分母和指标值；
- JSON：文件模式下的审计结果。

历史口径来源为 `stat_internet_line_metrics.py`，运行时不引用该文件。

每次以数据库模式成功计算时，程序会把 `end-month` 的基础指标写入
`orch_opening_monthly_summary`，并把数据质量写入
`orch_opening_monthly_quality`。逐月取数并计算后，历史月度汇总可供趋势、同比和环比使用。


## 自动率新版入口

省级移机在原始工单中先筛选订单类型=变更且调整类型为移机、部分移机、内部移机，再按订单号关联资管；自动率使用关联资管最新环节后的中间表，开通/变更有9类候选环节、拆除有6类。不因人员字段为 `/` 而整单剔除，逐环节仅统计非空、非 `/` 的有效处理人；整体分母为各环节有效次数之和。资管四环节未匹配记录或处理人为空时先留空，再只对空值应用路径规则：订单类型=变更且调整类型为停机或复机时，四个资管环节均填 `/`，不再因资管空值触发日志查询；开通及全部变更的组织资源释放填 `/`；互联网专线、MPLS-VPN专线、传输专线的归档审核填 `/`（不限制订单类型）。已有处理人或 `/` 不覆盖。拆除的组织资源释放、语音专线拆除的归档审核等其他缺失保持为空。资源查询受理人不做任何补填，语音拆除也不例外。asset_matches保留真实关联记录。不传Cookie不查询日志。传入时先重建当月中间表并应用路径规则，再对四个资管字段任一仍为空的订单抓取流程日志；不限定业务类型，不增加订单状态或订单类型限制，每单只请求一次。每环节取 updateDate 最新、同时间第一条；只修改仍为空的资管字段，保留已有处理人和 `/`。有效处理人正常回填；订单查询成功但查无订单、日志查询成功但没有指定环节时填 `/`；环节存在而处理人为空、网络、登录、权限、返回格式异常继续留空。运行命令需指定 `--asset-csv "当期资管专线.csv"`。规则版本为 `3.11.0-log-no-data-slash`；地市计算和绘图暂未迁移。详见 [automation_intermediate.README.md](automation_intermediate.README.md)。产品开通量口径不变。

中间表保留停机、复机数据并展示调整类型；移机汇总仅统计移机、部分移机、内部移机三类，停机和复机不计入移机自动率。

中间表业务范围：关联资管前，仅保留互联网专线、MPLS-VPN专线、传输专线、行业视频MV专线。其他业务不进入中间表，原始表数据不删除。四类业务的停机、复机仍保留，但不计入移机指标；空值填充及日志补齐规则不变。审计 excluded_other_businesses 记录业务范围过滤数。地市入口仅统计互联网专线，本次不会移除其业务数据，地市算法仍暂不迁移。

## 停复机自动率及本轮资管空值补填

互联网专线、MPLS-VPN专线、传输专线新增停复机指标。范围：统计月、已完成、订单类型=变更、调整类型为停机或复机；两者合并。四个环节为受理、资源查询、配置激活、报结，沿用非空且不等于 `/` 计分母、包含“自动”计分子的规则。整体按四环节有效次数加权。停复机不混入移机，行业视频MV本次不新增停复机页面。

新增指标继续写入 result_orchestration_opening：internet/mpls/transmission 前缀的 stop_resume_automation_rate（month_stage、month_city_stage、month_all_stages）及 stop_resume_activation_rate（month_city）。8月基准和环比暂为空，不显示环比，不填0%。


项目根目录命令（python3不可用时使用python）：

```powershell
python metrics/opening/dedicated_line_metrics.py --start-month 2025-10 --end-month 2026-09 --asset-csv "data/offline_data/结束时间为9月1日-9月30日的资管专线数据清单_1008.csv" --mode both
python reporting/build_internet_line_ppt.py --month 2026-09 --section 专线自动情况 --keep-json --output "outputs/monthly_report/专线自动情况_2026-09_含停复机.pptx"
```

省级自动率新增两页：互联网与VPN为第一页，传输为第二页。图片脚注原文保留。省级完整稿新增页为23、24，终端目录25、内容26～27，业务支撑目录28、内容29～30；地市版页码不变。
