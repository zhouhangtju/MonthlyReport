# 专线/专网重复投诉率

## 数据来源

数据库 `eoms_complaint` 数据集，即EOMS政企投诉工单。统计时根据 `派单时间`截取指定周期。

## 有效工单范围

1. `业务类别`包含“专线”或“专网”；
2. 非自建工单按 `客服流水号非空` 且 `工单状态=正常结束` 判定；不使用 `是否自建/isSelfbuild` 代替这两个条件；
3. 剔除 `工单主题`包含“重置鉴权码”的工单；
4. 客户标识优先使用 `计费号码`，计费号码为空时使用 `手机号码` 补位，两者均为空时不进入分母；取数链路可从附加报结信息和其他工单文本中补全 e55 计费号码；
5. 业务类别取“政企市场”节点之后的完整业务类别路径，不只取某一级节点。

## 分子与分母

重复投诉Key为：

```text
客户标识 + "|" + 政企市场后完整业务类别路径
```

- 分母：有效工单范围内的唯一客户标识数，不按工单数或重复投诉 Key 数统计；
- 仅分子剔除：同时满足 `退单原因非空`、`最后处理班组包含“政企头部客户重保组”` 且 `退单原因不包含“售中催单”` 的工单；这些工单仍保留在分母中；
- 1小时重复派单：同一Key按派单时间排序，相邻时间差小于或等于1小时的后一单从分子候选剔除；
- 分子：处理后仍出现至少2次的重复投诉Key数；
- 专线/专网重复投诉率 = 重复投诉Key数 / 唯一客户标识数。

一个客户可能在多条完整业务路径上分别形成重复 Key，因此分子重复 Key 数可能大于重复客户数。

本指标口径以 `export/EOMS-投诉工单工具包-精简版/scripts/政企投诉工单统计_客服流水号口径.py` 为准；不带“客服流水号口径”后缀的脚本属于历史入口。

## 运行与结果

```bash
python3 metrics/complaint/dedicated_line_repeat_complaint_rate.py \
  --database data/quality_assessment.db \
  --start-date 2026-08-01 \
  --end-date 2026-08-31 \
  --mode both
```

`--mode`可选 `file`、`database`或 `both`。数据库结果写入 `metric_run`、`ads_metric_result`和 `ads_metric_detail`；文件默认写入 `outputs/专线专网重复投诉率_起始日期_结束日期.json`。结果包含全省及地市维度，审计明细区分分母、分子和剔除记录。
