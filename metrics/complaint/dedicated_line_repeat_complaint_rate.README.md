# 专线/专网重复投诉率

## 数据来源

数据库 `eoms_complaint` 数据集，即EOMS政企投诉工单。统计时根据 `派单时间`截取指定周期。

## 有效工单范围

1. `业务类别`包含“专线”或“专网”；
2. 剔除 `是否自建/isSelfbuild=1`，不要求客服流水号非空；
3. 只保留工单状态为 `正常结束`、`已完成`或`完成`的工单；
4. 剔除 `工单主题`包含“重置鉴权码”的工单；
5. 客户标识优先使用 `计费号码`；附加报结信息中的 e55 可优先覆盖，计费号为空时从多个文本字段提取 e55，仍为空时使用手机号码；
6. 业务类别取第一个 `->` 之前的一级类别。

## 分子与分母

重复投诉Key为：

```text
客户标识 + "|" + 一级业务类别
```

- 分母：全部唯一 `客户标识|一级业务类别` Key 数；
- 整体剔除：`退单原因`非空、`最后处理班组`包含“政企头部客户重保组”、且退单原因不包含“售中催单”的工单；该规则同时影响分子和分母；
- 1小时重复派单：同一Key按派单时间排序，相邻时间差小于或等于1小时的后一单从分子候选剔除；
- 分子：处理后仍出现至少2次的重复投诉Key数；
- 专线/专网重复投诉率 = 重复投诉Key数 / 唯一客户标识数。

本指标口径以 `export/.../calc_zhuanxian_repeat_rate.py` 为准。

## 运行与结果

```bash
python3 metrics/complaint/dedicated_line_repeat_complaint_rate.py \
  --database data/quality_assessment.db \
  --start-date 2026-08-01 \
  --end-date 2026-08-31 \
  --mode both
```

`--mode`可选 `file`、`database`或 `both`。数据库结果写入 `metric_run`、`ads_metric_result`和 `ads_metric_detail`；文件默认写入 `outputs/专线专网重复投诉率_起始日期_结束日期.json`。结果包含全省及地市维度，审计明细区分分母、分子和剔除记录。
