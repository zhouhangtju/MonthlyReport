# 千里眼重复投诉率

## 数据来源

数据库 `eoms_complaint` 数据集，即EOMS政企投诉工单。统计时根据 `派单时间`截取指定周期。

## 有效工单范围

1. `业务类别`包含“千里眼”，或者包含“视频监控”但不包含“专线专网”；
2. `客服流水号`非空且 `工单状态=正常结束`；
3. 剔除 `工单主题`包含“重置鉴权码”的工单；
4. 客户标识优先使用 `计费号码`，为空时使用 `手机号码`，两者均为空则剔除；
5. 一级业务类别取完整业务路径中第一个 `->`之前的文本。
6. 所属区县可从投诉内容、退单附加说明、工单主题、下一环节区县和附加说明中补全；所属地市为空时，按浙江区县映射反推地市，或从投诉内容的 `【摄像头所属地市】` 补全。

## 分子与分母

重复投诉Key为：

```text
客户标识 + "|" + 一级业务类别
```

- 分母：有效工单中的唯一客户标识数；
- 分子候选剔除：`最后处理班组`包含“政企头部客户重保组”或“创新院”，或者 `结单人`为“周楷函”或“张艺飞”的工单；该规则不影响分母；
- 24小时重复派单：同一Key按派单时间排序，相邻时间差小于或等于24小时的后一单从分子候选剔除；
- 重复投诉Key：处理后仍出现至少2次的Key；
- 分子：命中重复投诉Key的唯一客户标识数；
- 千里眼重复投诉率 = 分子唯一客户标识数 / 分母唯一客户标识数。

“最后处理班组”和“结单人”按两个独立字段处理，不使用“最后处理人”替代结单人。

分母在指定班组/结单人剔除之前固定；这些工单只从分子候选中剔除。分子按命中重复 Key 的客户标识去重，不按重复 Key 数直接计数。

本指标口径以 `export/EOMS-投诉工单工具包-精简版/scripts/政企千里眼重复投诉率_客服流水号口径.py` 为准；不带“客服流水号口径”后缀的脚本属于历史入口。

## 运行与结果

```bash
python3 metrics/complaint/qianliyan_repeat_complaint_rate.py \
  --database data/quality_assessment.db \
  --start-date 2026-08-01 \
  --end-date 2026-08-31 \
  --mode both
```

`--mode`可选 `file`、`database`或 `both`。数据库结果写入 `metric_run`、`ads_metric_result`和 `ads_metric_detail`；文件默认写入 `outputs/千里眼重复投诉率_起始日期_结束日期.json`。结果包含全省及地市维度，审计明细区分分母、分子和剔除记录。
