# 互联网专线新装报障率 V2

`dedicated_line_install_fault_rate.py` 在文件内完成投诉筛选、新装关联和全省、地市统计，使用项目已有的 `metrics/installation/common.py` 和数据库公共模块。

## 口径

1. 新装来自 `orch_install`。采集接口已限定互联网专线；计算以订单创建时间限定统计期，产品实例编号、地市和时间必须有效。
2. 投诉来自 `eoms_complaint`。本文件直接判断`业务类别`包含“专线”或“专网”，规则与重复投诉率的业务分类一致。不要求只包含“互联网专线”，也不按`业务类型`字段筛选。
3. 匹配前剔除`是否退单`为`1`的投诉，兼容数值1、1.0及文本“1”“1.0”“是”（去除首尾空格）；空值保留。
4. 计费号码与产品实例编号一致、地市一致，投诉派单时间在统计期内且不早于订单创建时间。
5. 分母为有效新装记录数；分子为至少匹配到一张符合条件的非退单投诉的新装记录数。退单与非退单并存时仍可计入分子。多次投诉只计该新装记录一次，不按产品实例编号合并不同新装记录。

不引入重复投诉率的客服流水号、正常结束、重置鉴权码、重复时间间隔或班组排除规则。编号大小写、地市标准化及时间边界沿用原版。

## 运行

在项目根目录执行：

```bash
python3 metrics/installation/dedicated_line_install_fault_rate.py \
  --start-date 2026-06-01 \
  --end-date 2026-08-31 \
  --mode file
```

`file`模式仍从MySQL读取，但只输出JSON；`database`只保存数据库结果；`both`两者都保存（默认）。`--output`指定JSON路径，默认带`v2`以避免覆盖原版文件。

沿用指标代码`dedicated_line_install_fault_rate`及既有结果表，每次执行生成新的运行ID，版本为`2.0.0`。下游按最新成功运行读取该指标时可能读到V2；本入口不会自动修改其他脚本的调用关系。

质量统计保留原始投诉数量，并新增业务范围内、非业务范围排除、业务范围内退单排除、筛选后数量。这四项筛选计数针对载入的全部投诉；`complaint_rows_in_period`是进一步通过号码和统计期校验后的数量。

`details.excluded_complaints`保留业务范围与退单剔除原因，来源数据集标为`eoms_complaint`；数据库模式下有源记录ID的明细会持久化。JSON输出沿用原版公共报告格式，不包含逐条明细。
